# Working on PF2e Crafting

Use the installed Superpowers plugin for day-to-day work. Keep small, clear
changes lightweight. Use systematic debugging for unexpected behavior, focused
regression tests for changes to crafting math, dates, or saved data, and verify
the relevant checks before reporting success.

Use OpenSpec's core Codex skills for larger changes whose behavior needs a
lasting record, such as a new workflow, data format, or cross-device layout.
Explore when the behavior is unclear, then propose, apply, and archive the
change. Use the OpenSpec documents as the single plan; don't write a duplicate
Superpowers plan. Don't open a spec for routine fixes or cosmetic changes
unless requested.

This repo publishes an active site. Commit, push, and deploy only when requested.
